# Sport Group Management App for Community

## Overview
- Member accounts — registration, login, and account management
- Court booking — casual and competitive session booking
- Competitive ranking — Elo-based ranking system that matches players of similar skill
- Social features — forum posts, comments, and staff announcements
- Staff & admin tools — user moderation, session generation, match result logging

## Requirements
 
- Python 3.10+
- pip

## Installation

- Apply database migrations using       python manage.py migrate
- Create new superuser account using    python manage.py createsuperuser
- Run the server using                  python manage.py runserver
- Connect to http://127.0.0.1:8000/
